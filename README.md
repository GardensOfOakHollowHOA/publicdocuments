# The Gardens of Oak Hollow Homeowners Association
**Official Document Public Repository**

Welcome to the official public document site for **The Gardens of Oak Hollow Homeowners Association**, a Texas nonprofit homeowners association.

This site is maintained by the Association to provide homeowners access to recorded governing documents in accordance with **Texas Property Code § 207.006**.

## 📌 Access restrictions
This project is maintained by approved maintainers of the Gardens of Oak Hollow Homeowners Association that are provided access to the this Github Organization by the Executive Board. It is the responsibility of the Executive Board to maintain an approved list of maintainers be it direct Executive board members or an appointed maintainer.

## 📌 Annual Update requirements
Post Executive Board elections held in March of each year 
- The new President shall transfer ownership and access to the newly elected Executive Board President. 
- The new President shall update the Organization membership as required.
- The new President shall assign a maintainer if they choose.
- The gmail address credentials shall be transferred to the new President from the previous President. Only one (1) person shall have these credientials at a time to prevent account lock out and deletion from Google.

## 📌 Basic Maintenance and Site structure
This site is deploy using GitHub page when ever there are Committed changes made within GitHub ot updates are pushed into the repository. GitHub Pages uses Jekyll and Liquid.

- **_includes** folder are page fragments written in Liquid to perform repeatable rendering. For example render a folder of PDF files.
- **_layouts** folder has teh pages default layout providing a consistent page header and footer layout.
- **assets** folder contains the style sheet defining CSS.
- **documentarchive** folder will house archival documents. This could be old versions of ByLaws for example.
- **forms** folder contains association forms for residents.
- **governance** folder contains recorded documents of the association and design guides.
- **meetingminutes** folder contains meeting minutes from Association meetings.
- HTML pages are stored at the site root.
- Other files are there for GitHub Pages handling and should not be modified (_config.yml)
